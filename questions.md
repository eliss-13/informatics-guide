# Вопросы для самопроверки
1. **Вопрос:** Что такое система счисления?
   **Ответ:** Совокупность правил записи чисел с помощью определенного набора символов.
2. **Вопрос:** Сколько бит в одном байте?
   **Ответ:** 8 бит.
3. **Вопрос:** Какое основание у двоичной системы счисления?
   **Ответ:** Основание 2 (используются только цифры 0 и 1).
